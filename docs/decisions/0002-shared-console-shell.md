# ADR 0002 — 평면 콘솔과 공통 셸

- 상태: 채택
- 결정일: 2026-09-28
- 현재 계약: [콘솔 화면](../UI_UX.md), [디자인 시스템](../DESIGN_SYSTEM.md)

## 배경

개별 생성 이미지의 헤더·질문 위치·코어 경로가 달라 같은 앱의 상태 변화로 읽히지 않았다. 사용자는 평면 콘솔을 선택했고 입체 시안 폐기와 화면의 프로젝트명 제거를 요청했다.

## 선택과 근거

| 대안 | 판정 |
|---|---|
| 이미지마다 헤더를 다시 생성 | 공통 규격을 집행할 수 없어 정렬 차이가 반복될 수 있음 |
| 공통 헤더 이미지를 합성 | 모양은 맞출 수 있으나 긴 질문·확대·키보드·실제 조작의 검증 근거가 부족함 |
| 공통 셸과 코어 컴포넌트에서 상태별 화면 렌더 | 채택. Single source of truth로 좌표·표제·메뉴·경로를 한 곳에서 소유하고 실제 DOM으로 조작과 reflow 확인 |

기본 경험은 평면 MAGI 표시장치다. 입체 표현은 코어를 물리적인 버튼으로 읽게 하며 사용자가 선택한 화면 감성과 맞지 않아 제외했다. 공개 프로젝트명은 유지하며 콘솔에는 단일 콘솔 표제만 표시한다. 기본 표제는 MAGI COMMAND CONSOLE이며 좁은 화면의 축약형과 macOS 표시명은 화면 계약을 따른다.

## 결과

공통 헤더와 안건 영역은 상태별로 다시 작성하지 않는다. 대기·검토·완료의 코어 기하는 동일하고 상세 열람은 같은 기하의 축약 표현이다. 시각 수용은 같은 크기의 브라우저 렌더링과 좌표 비교를 포함한다. 디자인 검토본은 모델 실행·영속 저장·native 권한의 구현 증거를 대신하지 않는다.
