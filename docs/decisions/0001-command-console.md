# ADR 0001 — 로컬 자료를 심의하는 팬 콘솔

- 상태: 채택
- 결정일: 2026-09-28
- 현재 계약: [제품 설계](../DESIGN.md), [심의](../DELIBERATION.md), [아키텍처](../ARCHITECTURE.md), [콘솔 화면](../UI_UX.md)

## 배경

사용자는 자신의 맥에 저장된 원문을 사용자 소유 모델로 검토하면서 MAGI의 화면을 경험하는 무료 팬 제품을 원한다. 세 역할의 검토가 의사결정에 도움이 되려면 입력, 표결 대상, 이견과 권한을 추적할 수 있어야 한다. 일반 채팅 UI와 범용 자동개발 흐름은 이 목표의 중심을 충분히 표현하지 못한다.

## 검토한 대안과 선택

| 결정 | 검토한 대안 | 선택·원칙·제품 효과 | 선택의 부담 |
|---|---|---|---|
| 제품 형태 | 브라우저 서비스 / macOS 데스크톱 | 데스크톱. 사용자가 고른 자료의 원문 접근과 공식 로컬 에이전트 실행을 같은 권한 경계에서 다룸 | OS 권한·배포 서명·외부 프로세스 수명을 직접 관리 |
| UI 구현 | SwiftUI 중심 / Electron / Tauri + React·SVG | Tauri 2의 Rust host와 React·SVG. 권한을 host에 모으는 least privilege와 단방향 의존, 기하·타이포·모션 토큰 재사용 | WebView와 host 경계의 DTO·접근성·프로세스 적합성 검증 필요 |
| 검토 방식 | 세 답변 단순 합성 / 제한 없는 반복 토론 / 고정 단계 심의 | 독립 검토→교차 검토→단일 문안→봉인 표결. 입력 독립성과 유한 실행으로 정보 오염·무한 반복을 줄임 | 추가 지연과 호출량; 정확도 향상 자체는 보장하지 않음 |
| 결과 권위 | LLM의 최종 요약 / 앱의 결정적 집계와 표결 문안 | 앱 집계와 동일 문안. Single source of truth로 표결 대상과 사용자 결과의 의미 차이를 막음 | 구조화 검증·schema·내용 digest 관리 필요 |
| 자료 방식 | 전체 PC 검색 / 사용자가 고른 불변 캡처 | 선택 범위와 반출 목적지를 고정. 최소 권한과 provenance로 원문·가공본·실제 읽은 범위 연결 | 캡처·추출·범위 미리보기·보존·삭제 설계 필요 |
| 모델 연결 | 운영자 게이트웨이 / 사용자 구독·BYOK | 검증된 공식 사용자 연결. 공급자 비용과 인증 주체를 사용자 경로에 유지 | 프로토콜 기능·정책·도구 차단을 경로별로 검증 |
| 실행 상태 | 화면 메모리 / 서버 상태 / 로컬 영속 host | Rust host + SQLite가 명령·이벤트·상태를 원자적으로 소유. 재시작·중복·다중 창 일관성 | 마이그레이션·원격 요청 미확인 상태·백업 복구 처리 |
| 시각 표현 | 세 카드 채팅 / 3D 사령실 / 평면 MAGI 표시장치 | 삼각 코어·중앙 결의·강한 표제의 표시장치. 사용자가 명시한 시각 목표와 정보 위계에 맞춤 | 다각형 영역의 텍스트·좁은 창·VoiceOver를 별도로 설계 |
| 공개 코드 | MIT / Apache-2.0 | 사용자 선택 MIT. 짧은 재사용 조건과 팬 표현 권리의 별도 고지 | 제삼자 자산·원작 권리는 별도 확인 |

SwiftUI의 OS 통합과 Electron의 런타임 일관성도 타당한 장점이다. 선택은 이 제품에서 웹 기반 시각 시스템과 좁은 native 권한 경계를 함께 유지하려는 설계 판단이다. Tauri를 사용한다는 사실만으로 외부 에이전트의 파일·네트워크 권한이 제한된다고 보지 않는다.

## 결정의 결과

팬 표현과 심의 엔진은 별도 모듈 경계로 둔다. 화면은 실제 영속 이벤트를 표현하고, 모델의 자유문장으로 실행 상태를 바꾸지 않는다. 모델 연결은 공식 인증과 능력 검증을 통과해야 사용할 수 있다. 자료·역할·출력의 프롬프트 지시는 host 권한을 늘리지 못한다.

합의의 질을 모델 수로 설명하지 않는다. 동일 모델·동일 제공자와 사용량 미확인을 표시한다. 반대·기권·미결은 정상적인 결과로 보존한다. 보류나 이견 자체를 오류로 취급해 재실행하지 않는다.

MIT는 프로젝트 기여자가 권리를 가진 코드와 문서에 적용한다. 무료 팬 앱의 배포 정책과 원작 권리는 별도다. 상업 프로젝트에 인계하는 계약은 [중립적 검토 프로세스](../REUSE.md)로 정리한다.

## 재검토 조건

선택한 UI 런타임이 실제 접근성·성능 목표를 충족하지 못하거나, 공식 공급자 경로의 권한 경계를 집행할 수 없거나, 원작 표현의 배포 조건이 제품 정체성과 양립하지 못하면 관련 결정을 재검토한다. 새 결정은 별도 ADR로 남기고 정본에는 채택된 목표만 유지한다.
