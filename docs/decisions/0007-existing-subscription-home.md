# ADR 0007 — 기존 구독 인증 홈을 사용하는 연결 프로필

- 상태: 채택
- 현재 계약: [공급자 인증](../SECURITY.md#provider-auth), [연결 화면](../UI_SCREENS.md)

## 배경과 대안

사용자는 이미 인증된 CLI 구독을 여러 연결 프로필로 선택한다. 앱 전용 로그인이나 API 키를 추가하면 별도 인증·과금 경로가 생기며 이 제품의 구독 연결 계약과 달라진다. 인증 파일을 실행 공간에 복제하거나 인증 홈을 런타임 홈으로 그대로 전달하면 원본 설정·기록 읽기와 인증 저장소 쓰기를 함께 허용할 수 있다.

## 결정

사용자가 직접 입력한 인증 홈을 프로필의 읽기 권위로 고정하고 실행 공간과 분리한다. 홈 경로는 `~/`로 표시하며 기본 홈과 커스텀 홈을 별도 흐름으로 구분하지 않는다. 프로필 추가와 편집은 같은 모달에서 수행한다. 앱은 별도 ChatGPT 로그인 버튼을 제공하지 않는다.

최소 권한 원칙에 따라 인증 broker는 선택한 계정의 기존 구독 인증을 제한된 메모리 메시지로 전달한다. 실행물은 [런타임 신뢰 결정](0004-provider-runtime-trust.md)에 따라 전체 구성과 출처를 검증한다. 앱은 인증 파일을 복제하거나 원본에 쓰지 않는다.

## 결과

프로필 변경은 새 revision과 모델 binding의 재검증을 요구한다. 계정·인증 방식·모델을 자동 대체하지 않는다. 인증 없음과 연결 확인 불가를 구분하며, 다른 프로필의 실패가 선택한 프로필의 인증 상태를 덮어쓰지 않는다.
