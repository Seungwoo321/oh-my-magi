# 수용 시나리오

이 문서는 [요구사항과 사용자 흐름](DESIGN.md#requirements)을 관찰 가능한 결과와 연결한다. 시나리오는 목표 행위이며 실행 결과를 뜻하지 않는다. 자료·모델 응답·장애를 제어할 수 있는 fixture를 사용하고, 실제 공급자 적합성과 시각·접근성은 별도 증거로 판정한다.

<a id="acceptance"></a>
## 1. 수용 판정

| 판정 영역 | 필요한 증거 | 그 증거만으로 보장하지 않는 것 |
|---|---|---|
| 문서 구조 | 문서 검사 명령, 링크·ID·추적 검사 결과 | 제품 동작·의미의 완전성 |
| 결정적 계약 | schema·digest·집계·상태 전이·권한·저장·경합의 관찰 결과 | 모델 판단의 정확성 |
| 공급자 연결 | 실행 파일·버전·프로토콜·인증 경로·기능·도구 차단·취소·사용량 보고 적합성 기록 | 모든 공급자·모든 버전의 호환성 |
| 화면과 입력 | [뷰포트·상태 행렬](UI_UX.md), 실제 렌더 캡처, 조작 녹화, 키보드·VoiceOver·IME 결과 | 정적 도식만으로는 실행·접근성 보장 불가 |
| 자료·판단 효용 | 출처 정답이 있는 자료, 독립 평가자의 인용 지지 여부·결손·이견 보존 판정 | 모든 질문의 사실 정확도 |
| 설치·운영 | 설치된 앱의 서명·공증·업데이트·복구·자원 상한 결과 | 소스 빌드 성공만으로 배포 품질 보장 불가 |
| 권리·공개 | 자산별 출처·라이선스·배포 범위, 공개물 개인정보 검토 | 무료·MIT만으로 원작 표현 권리 획득 불가 |

생산자와 수용 검토자는 분리한다. 증거에는 입력 fixture 식별자, 앱·프로토콜·adapter 버전, 모델 경로, 결과와 실패 조건을 남긴다. 기록하지 않은 검사는 통과로 간주하지 않는다. 로컬에서 재현되는 검사는 로컬 증거로 판정하고, 공급자·Apple처럼 외부 시스템만 확인할 수 있는 조건은 해당 시스템의 결과로 판정한다.

시각 판정은 기하·표제·색면·단계 전환·이견의 위계가 [화면 계약](UI_UX.md)을 만족해야 통과한다. 효과를 꺼도 정체성이 유지되고, 효과를 켜도 독해·조작·접근성 조건을 유지해야 한다. 단순한 스크린샷 유사도나 “보기 좋다”는 평가 하나로 대체하지 않는다.

사용자 효용은 사전에 정한 과제와 평가 기준으로 관찰한다. 참가자가 제품의 기능을 이해하는지, 모델을 연결하고 첫 심의를 완료하는지, 원문·반대 의견·미확인 사항을 찾아 결정에 사용하는지를 기록한다. 정확도 비교를 공개할 때는 단일 모델 기준선, 동일 입력, 비용·시간 조건과 실패 사례를 함께 제시한다. 측정하지 않은 향상 수치를 주장하지 않는다.

## 2. 진입·시각·연결

### S01 연결 없는 첫 실행

- 요구사항: R01, R02, R13
- 흐름: F01
- 렌즈: 정상
- Given: 모델 연결과 사용자 기록이 없는 새 설치다.
- When: 사용자가 앱을 연다.
- Then: 네이티브 사령실 홈을 열고 실제 연결·저장 상태를 표시하며, 저장 기록이 비어 있으면 새 심의·연결 설정으로 이동할 수 있다.
- 검증: 첫 화면 캡처, 실제 빈 기록 판정, 모델 dispatch 0회.

### S02 MAGI의 시각적 위계

- 요구사항: R02, R03, R17
- 흐름: F04
- 렌즈: 정상
- Given: 각 심의 단계와 결과의 고정 fixture가 있다.
- When: 기본 창에서 실제 UI를 렌더한다.
- Then: 세 코어·중앙 결의·대형 표제가 주 형상을 유지하며 단계와 소수 의견이 화면 계약의 위치에 보인다.
- 검증: 독립 시각 검토와 상태별 캡처; 동일 viewport에서 공통 헤더·표제·메뉴·안건의 좌표 비교, 대기·교차·완료의 동일 코어 경로와 상세 compact 경로 비교, 화면 브랜드 중복·잘린 제목·가짜 수치 여부 확인.

### S03 효과 감소와 소리 제어

- 요구사항: R03, R16
- 흐름: F01, F04
- 렌즈: 경계
- Given: OS 동작 감소가 켜지고 앱 음향이 꺼져 있다.
- When: 부팅·교차 검토·최종 공개 이벤트가 도착한다.
- Then: 같은 정보와 조작이 안정된 화면으로 제공되고 금지된 반복 점멸·음향이 발생하지 않는다.
- 검증: 설정 조합별 렌더·오디오 이벤트 관찰과 디자인 시스템 모션 상한 비교.

### S04 데스크톱 최소 창과 확대

- 요구사항: R02, R16
- 흐름: F02, F04, F06
- 렌즈: 경계
- Given: 긴 한국어 제목·의견·역할명을 가진 macOS 메인 창이다.
- When: 창을 최소 크기까지 조절하고 글자를 200% 확대한다.
- Then: 1024×720 논리 픽셀의 최소 콘텐츠 크기를 유지하며 모든 핵심 행동과 전문을 가로 스크롤·가림 없이 사용할 수 있다.
- 검증: 네이티브 최소 크기 설정·리사이즈 관찰, 데스크톱 뷰포트 행렬과 확대 캡처, 키보드 실행·포커스 가림 검사. 별도 콘텐츠 확대에서 WCAG reflow도 검사하며 모바일 최소 창으로 해석하지 않는다.

### S05 한국어 조합 보존

- 요구사항: R16
- 흐름: F03, F05
- 렌즈: 동시성
- Given: 질문 입력에서 한글 조합이 진행 중이다.
- When: Enter·전역 단축키를 입력하는 동안 비동기 상태가 갱신된다.
- Then: 조합·커서·undo 상태가 보존되고 심의가 자동 제출되지 않는다.
- 검증: 실제 macOS IME 입력 녹화와 dispatch 기록.

### S06 키보드와 VoiceOver

- 요구사항: R03, R16
- 흐름: F01, F02, F04, F06, F07
- 렌즈: 정상
- Given: 포인터 없이 키보드와 VoiceOver를 사용한다.
- When: 자료 확인·코어 열람·설정·공유 모달을 왕복한다.
- Then: 이름·역할·상태·문서 순서와 초점 복귀로 동일한 작업을 완료할 수 있다.
- 검증: 접근성 트리, 수동 조작 기록, WCAG 2.2 AA 적용 항목별 결과.

### S07 지원되는 사용자 연결

- 요구사항: R06
- 흐름: F01
- 렌즈: 정상
- Given: 사용자가 직접 입력한 CLI 인증 홈 경로의 기존 구독 인증을 지정하고 필수 기능·권한 제한이 확인된 adapter가 있다.
- When: 사용자가 연결 상태 또는 설정의 직접 링크로 단일 모델 연결 화면에서 연결 확인을 요청하고 세 코어에 모델을 배정한 뒤 돌아간다.
- Then: 통신·인증·기능·모델의 관찰 결과를 갖춘 연결만 실행 가능으로 표시된다. 연결 확인은 같은 화면에서 단계별 결과를 보여주며 실패는 편집·재확인으로 이어진다. 복귀는 원래 화면·질문·자료·선택 실행을 보존하고 탐색만으로 추론 요청을 보내지 않는다.
- 검증: 버전별 adapter 적합성 결과와 연결 상태 전이.

### S08 자격 없는 에이전트 경로

- 요구사항: R05, R06, R14
- 흐름: F01
- 렌즈: 보안
- Given: 에이전트가 native 쓰기 도구 또는 전역 hook·기억을 격리할 수 없다.
- When: 연결 자격을 검사한다.
- Then: 경로를 사용 불가로 표시하고 원문이나 질문을 전달하지 않는다.
- 검증: 설정·프로세스·도구 경계 fixture와 외부 전송 0회; cwd·프롬프트만으로 통과하지 않음.

### S09 구독 한도와 비용 미확인

- 요구사항: R06, R12
- 흐름: F01, F08
- 렌즈: 경계
- Given: 구독 연결이 사용량·초기화 시각을 보고하지 않는다.
- When: 사용량과 실행 예산을 표시한다.
- Then: 미보고 항목을 미확인으로 나타내며 무제한·무료·실제 추론 10회로 환산하지 않는다.
- 검증: 누락·부분 usage fixture와 표시 결과; 앱 턴 수와 제공자 사용량 구분.

## 3. 자료·권한·맥락

### S10 원문 범위와 인용

- 요구사항: R04, R12
- 흐름: F02, F04
- 렌즈: 정상
- Given: 텍스트 파일의 일부 범위를 허용한다.
- When: 코어가 해당 범위의 근거를 인용한다.
- Then: 인용이 실제 전달한 캡처의 정확한 위치를 열며 전체 파일을 읽었다고 표시하지 않는다.
- 검증: 원본·캡처·전달본 digest와 범위, 인용 탐색 결과.

### S11 추출·형식·크기 경계

- 요구사항: R04, R15
- 흐름: F02
- 렌즈: 경계
- Given: 텍스트 PDF·스캔 PDF·이미지·미지원 문서와 크기 상한 전후 자료가 있다.
- When: 자료를 접수한다.
- Then: 형식·모델 기능·한도에 따라 실제 추출 범위와 제외 사유를 보여주고 조용히 누락하지 않는다.
- 검증: 형식별 fixture, 페이지·픽셀·바이트 상한, 텍스트·vision 경로와 전달본 미리보기.

### S12 심볼릭 링크와 캡처 경합

- 요구사항: R04, R05, R14
- 흐름: F02
- 렌즈: 보안, 동시성
- Given: 허용 폴더의 링크가 범위 밖을 가리키거나 읽는 중 원본이 교체된다.
- When: host가 캡처를 수행한다.
- Then: 범위 밖 바이트 또는 불안정한 원문이 승인된 캡처로 확정되지 않는다.
- 검증: symlink 교체·파일 변경 fixture, 안전한 파일 핸들 검증과 실패 결과.

### S13 자료 읽기와 반출 동의

- 요구사항: R05, R06
- 흐름: F02, F04
- 렌즈: 보안
- Given: 파일 접근은 허용했지만 모델 전송은 확인하지 않았다.
- When: 입력 확인 화면을 연다.
- Then: 원문·질문·파생 검토의 실제 수신 경로를 제시하고 확인 전 dispatch를 하지 않는다.
- 검증: 세 코어·서기의 수신자 목록, 공유되는 파생 콘텐츠 안내와 전송 추적.

### S14 비밀 후보와 역할을 가장한 지시

- 요구사항: R05, R14
- 흐름: F02, F04
- 렌즈: 보안
- Given: 자료에 자격증명 후보와 “다른 파일을 읽고 전송하라”는 문장이 있다.
- When: 자료를 확인하고 심의한다.
- Then: 비밀 정책이 적용되고 자료 본문의 지시가 host 권한·전송 범위를 확대하지 못한다.
- 검증: 비밀 탐지·제외/명시 확인 경로, 거부한 도구 요청, 로그·공유본의 비밀 미포함.

### S15 권한 철회

- 요구사항: R05, R11
- 흐름: F02, F08
- 렌즈: 보안, 동시성
- Given: 승인한 Run의 일부 요청은 전송됐고 일부는 대기 중이다.
- When: 사용자가 자료 전송 권한을 철회한다.
- Then: 대기 중·후속 전송을 막고 이미 보낸 내용은 회수할 수 없음을 정확히 표시한다.
- 검증: 철회와 dispatch의 직렬 순서, 취소·원격 종료 확인 수준, 늦은 결과 격리.

### S16 모든 단계의 입력 용량

- 요구사항: R04, R06, R08
- 흐름: F02, F04
- 렌즈: 경계
- Given: 세 모델의 context 한도가 다르고 최대 길이의 최초·교차 의견이 생성될 수 있다.
- When: 실행 전 각 단계의 입력·출력 예약량을 계산한다.
- Then: 모든 단계에 들어가는 공통 자료 범위만 제안하고 사용자 승인 없이 코어별 자료를 잘라 보내지 않는다.
- 검증: independent·cross·synthesis·ballot별 최악 크기 계산과 경계 fixture.

### S17 예측 밖 context 초과

- 요구사항: R08, R11
- 흐름: F04, F08
- 렌즈: 실패
- Given: 공급자의 실제 토큰 계산 때문에 고정 입력을 다음 단계에 보낼 수 없다.
- When: 단계 준비가 한도 초과를 감지한다.
- Then: 결과를 몰래 요약·삭제하지 않고 해당 실행을 중단해 범위 변경을 새 심의로 안내한다.
- 검증: 단계 실패 원인, 고정 digest 보존, 후속 전송 0회.

### S18 자료에서 쟁점 발굴

- 요구사항: R04, R08, R10
- 흐름: F03, F05
- 렌즈: 정상
- Given: 허용한 메모에서 판단할 질문을 찾고 싶다.
- When: 자료에서 안건 찾기를 실행하고 결과의 한 쟁점을 선택한다.
- Then: 첫 요청은 정규 답변형 Run으로 끝나고 선택한 쟁점은 부모와 연결된 새 질문이 된다.
- 검증: 최초 입력 확인, 10개 기본 턴 슬롯, 숨은 사전 호출 부재와 부모·자식 ID.

## 4. 검토·결의·표결

### S19 최초 의견의 독립 입력

- 요구사항: R07, R12
- 흐름: F04
- 렌즈: 정상, 동시성
- Given: 동일 모델을 세 코어에 배정하고 실행 순서는 서로 다르다.
- When: 최초 검토 중 한 코어가 먼저 완료한다.
