# Oh My MAGI!

**내 맥의 자료를 세 관점으로 심의하는 MAGI 커맨드 콘솔.**

Oh My MAGI!는 에반게리온의 MAGI에서 영감을 받은 무료 팬 프로젝트다. 사용자는 자신의 모델 구독 또는 API 키를 연결하고, 질문과 허용한 로컬 자료를 MELCHIOR-1·BALTHASAR-2·CASPER-3에 제출한다. 세 코어의 검토, 이견, 표결과 결의가 하나의 `MAGI COMMAND CONSOLE`에 나타난다.

제품의 중심은 MAGI다운 화면과 검토 가능한 답변이다. 삼각 코어 구조, 큰 기계식 표제, 각진 면과 신호선, 심의에 동기화되는 연출을 기본 경험으로 제공한다. 근거의 출처, 실제로 읽은 범위, 소수 의견과 미결 상태를 함께 보여준다. 앱의 짧은 표시명은 `MAGI CONSOLE`이다.

배포 대상은 설치형 macOS 데스크톱 앱이다. Tauri 2·Rust 실행 코어와 앱 안의 WebView 화면을 사용한다. 메뉴 막대의 상태 팝오버에서 심의를 확인하고 같은 안건의 콘솔로 복귀한다. 웹 서비스와 모바일 클라이언트는 제공 범위에 포함하지 않는다.

## 사용과 데이터의 경계

앱은 분석과 의사결정을 지원한다. 원본 파일 수정, 명령 실행, 배포, 구매 같은 외부 행동은 수행하지 않는다. 로컬 자료 접근과 모델 제공자에게 자료를 보내는 권한을 각각 확인한다. 로컬 앱을 사용해도 클라우드 모델을 선택하면 승인한 내용이 해당 제공자에게 전달된다.

앱 사용료는 없다. 모델 구독의 사용량 제한과 API 비용은 사용자가 선택한 제공자의 조건을 따른다. 구독 사용량을 무제한으로 표시하거나 자체 LLM 구독을 재판매하지 않는다.

## 문서 검사

```sh
node scripts/check-docs.mjs
node scripts/check-ui-design.mjs
```

문서 검사는 로컬 링크·앵커·요구사항과 시나리오 연결을 확인한다. UI 설계 검사는 화면·상태 목록과 renderer의 대응, HTML 생성과 탐색 목적지를 확인한다. 시각 품질·실제 조작·네이티브 동작은 [수용 시나리오](docs/SCENARIOS.md)에 따라 별도로 판정한다.
